You'll throw away the Vite welcome screen and render a list from an array.

## Edit App.tsx

<Playground template="react-ts" files={{
  "/App.tsx": `const todos = [
  { id: 1, text: "Read the React docs" },
  { id: 2, text: "Build a TODO app" },
  { id: 3, text: "Deploy it to Render" },
]

export default function App() {
  return (
    <main style={{ fontFamily: "system-ui", padding: 24 }}>
      <h1>My TODOs</h1>
      <ul>
        {todos.map(todo => (
          <li key={todo.id}>{todo.text}</li>
        ))}
      </ul>
    </main>
  )
}`
}} />

<Hint title="Why the `key` prop?">
React uses `key` to identify which items changed between renders. Without a stable key, React falls back to index-based diffing, which causes weirdness when items reorder or get removed.
</Hint>
