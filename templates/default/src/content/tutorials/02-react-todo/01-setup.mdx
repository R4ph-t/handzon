You'll boot the dev server and confirm hot reload before writing a line of TODO code.

<Callout type="tip">
The commands below have tabs for npm, pnpm, and yarn — pick the one you have installed.
</Callout>

## Install dependencies

<Tabs items={[
  { label: "npm",  value: "npm" },
  { label: "pnpm", value: "pnpm" },
  { label: "yarn", value: "yarn" }
]} group="pm">
  <Tab value="npm">
    ```bash title="Terminal"
    npm create vite@latest todo -- --template react-ts
    cd todo && npm install
    ```
  </Tab>
  <Tab value="pnpm">
    ```bash title="Terminal"
    pnpm create vite todo --template react-ts
    cd todo && pnpm install
    ```
  </Tab>
  <Tab value="yarn">
    ```bash title="Terminal"
    yarn create vite todo --template react-ts
    cd todo && yarn
    ```
  </Tab>
</Tabs>

Your project tree should look like this:
