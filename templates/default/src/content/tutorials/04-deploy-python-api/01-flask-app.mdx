## The app

```python title="app.py"
from flask import Flask, jsonify
import os

app = Flask(__name__)

@app.get("/healthz")
def health():
    return jsonify(status="ok")

@app.get("/items")
def items():
    return jsonify(items=[
        {"id": 1, "name": "Render"},
        {"id": 2, "name": "Astro"},
        {"id": 3, "name": "Flask"},
    ])

if __name__ == "__main__":
    app.run(host="0.0.0.0", port=int(os.environ.get("PORT", 8000)))
```

<Callout type="warn">
Binding to `0.0.0.0` (not `127.0.0.1`) and reading `PORT` from the environment are both **required** for Render — and most container hosts. Skip them and the platform health check fails.
</Callout>
