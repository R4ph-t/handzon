SQL's `SELECT` statement is the foundation of every read query.

## Anatomy of a SELECT

```sql title="Anatomy"
SELECT column1, column2          -- projection
FROM table_name                  -- source
WHERE condition                  -- filter
ORDER BY column1 ASC             -- sort
LIMIT 10;                        -- cap rows
```

## Try it

Imagine a `users` table:

```sql title="users"
| id | name    | age | country |
|----|---------|-----|---------|
| 1  | Ada     | 31  | UK      |
| 2  | Linus   | 54  | FI      |
| 3  | Margaret| 87  | US      |
| 4  | Donald  | 87  | US      |
```

Get all American users older than 50, name only:

```sql
SELECT name
FROM users
WHERE country = 'US' AND age > 50
ORDER BY age DESC;
```
