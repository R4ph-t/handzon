You'll commit the project, push to GitHub, and let Render do the rest.

## The Blueprint

```yaml title="render.yaml"
# yaml-language-server: $schema=https://render.com/schema/render.yaml.json
services:
  - type: web
    name: my-python-api
    runtime: docker
    plan: starter
    dockerfilePath: ./Dockerfile
    healthCheckPath: /healthz
    envVars:
      - key: PORT
        value: "8000"
    pullRequestPreviewsEnabled: true
```

<Callout type="tip">
`healthCheckPath` tells Render which URL to ping to decide if your service is alive. We wrote `/healthz` in step 1 specifically so this contract holds.
</Callout>

## Push and deploy

<Terminal entries={[
  { command: "git init && git add . && git commit -m 'init: flask api'" },
  { output: "[main (root-commit) 8f4d2e1] init: flask api" },
  { command: "git remote add origin git@github.com:you/my-python-api.git" },
  { command: "git push -u origin main" }
]} />

Then in the Render Dashboard:

<Steps>
  <Step title="New → Blueprint">Render reads `render.yaml` from the repo root.</Step>
  <Step title="Connect your repo">Render lists your accessible GitHub repos. Pick this one.</Step>
  <Step title="Confirm services">Review the proposed service. Click "Apply".</Step>
  <Step title="Wait for first deploy">~2 minutes for a small Flask app.</Step>
</Steps>

## Verify

```bash
curl https://my-python-api.onrender.com/healthz
# {"status":"ok"}
```
