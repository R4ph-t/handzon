## The content model

Every tutorial lives in a single folder under `src/content/tutorials/`:

<FileTree paths={[
  "src/content/tutorials/authoring-101/_meta.json",
  "src/content/tutorials/authoring-101/01-welcome.mdx",
  "src/content/tutorials/authoring-101/02-mdx-basics.mdx",
  "src/content/tutorials/authoring-101/03-interactive-components.mdx",
  "src/content/tutorials/authoring-101/04-publishing.mdx",
]} />

- `_meta.json` describes the tutorial (title, tags, difficulty, AI config…).
- Numbered MDX files become the steps in order. The number is just for sorting.
- Everything else is regular MDX with a global set of components available.
