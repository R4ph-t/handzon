Every component below is **globally available** in MDX — no imports needed.

## Callouts

```mdx
<Callout type="info">Heads up.</Callout>
<Callout type="tip">A nudge in the right direction.</Callout>
<Callout type="warn">Stop and read this.</Callout>
<Callout type="danger">Don't do this in production.</Callout>
```

<Callout type="tip">Tips share the accent color.</Callout>

## Collapsible sections

Use `Collapsible` for optional or supporting detail the learner can skip. Unlike `Hint`, it carries no "answer" framing, so it suits asides, extra background, or long output. Add `open` to start expanded.

```mdx
<Collapsible title="Why does this work?">
The runtime walks the tree and resolves each node in order.
</Collapsible>
```

## Images with captions

Plain markdown images get a border automatically. Use `Figure` when you also want a caption, and pass `width` to keep an image from filling the column. A `src` that points at a co-located `assets/` file is optimized through Astro automatically; `public/` paths like the logo below render as-is.

```mdx
<Figure
  src="/logo.svg"
  alt="The Handzon logo"
  caption="Figures add a border and an optional caption."
  width={180}
/>
```

## Steps (sub-step lists inside a page)

```mdx
<Steps>
  <Step title="First do this">Some explanation.</Step>
  <Step title="Then this">More explanation.</Step>
</Steps>
```

<Steps>
  <Step title="First do this">Some explanation.</Step>
  <Step title="Then this">More explanation.</Step>
</Steps>

Nest a `<Steps>` block inside a `<Step>` for sub-steps. Nested items number as `1.1`, `1.2`, and so on.

<Steps>
  <Step title="Set up the project">
    Get the basics in place:

    <Steps>
      <Step title="Install dependencies">Run the installer.</Step>
      <Step title="Start the dev server">Open the local URL.</Step>
    </Steps>
  </Step>
  <Step title="Build the first feature">Now you're ready to write code.</Step>
</Steps>

## Code blocks

Fenced code blocks pass through Expressive Code. You get **titles**, **line highlights**, **diff markers**, **copy-to-clipboard** out of the box.

```ts title="src/lib/math.ts" {2,4-5}
export function add(a: number, b: number) {
  return a + b;
}
export function mul(a: number, b: number) {
  return a * b;
}
```

```diff lang="ts" title="diff: tighten types"
- function add(a, b) {
+ function add(a: number, b: number) {
    return a + b;
  }
```

## Embeds

Use `Embed` for hosted video or slides that should sit inside the lesson. Set `type="slides"` for a deck, and pass `slide` when the deck should open at a specific slide.

<Embed
  type="slides"
